# TaskFlow MVP

MVP giao việc theo cây tài khoản, chạy thử không cần cài framework.

## Chạy thử

Yêu cầu Node.js 18+.

```bash
node local-server.mjs
```

Mở `http://localhost:4173`.

Tài khoản demo: `admin`, `cap1`, `cap2`; mật khẩu: `123456`.

Dữ liệu demo được lưu trong `localStorage` của trình duyệt để có thể thử nhanh. `schema.sql` là cấu trúc MySQL nền tảng cho bước chuyển sang PHP/MySQL; bản này chưa kết nối database thật.
